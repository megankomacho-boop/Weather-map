# 地図で調べる明日の天気・標高・水深

地図上の地点をクリックすると、その地点の緯度・経度と明日の天気予報を表示します。陸上では標高、海上では海底までの水深の目安も確認できます。

高校「情報Ⅰ」でWeb APIの仕組みを学ぶ教材として、ChatGPTの支援を受けて作成しました。

| 世界版 | [API_世界の天気マップ.html](./API_世界の天気マップ.html) | World Street Map（Esri） |

## 使い方

HTMLファイルをダウンロードしてブラウザで開き、調べたい地点をクリックします。地図の表示とデータの取得にはインターネット接続が必要です。

## データを取得する仕組み

1. Leafletを使い、地図上でクリックした地点の緯度・経度を取得します。
2. JavaScriptがその座標を使って、Open-Meteoに明日の天気予報を、GEBCOに標高・水深のデータを問い合わせます。
3. 受け取ったデータを読み取り、画面に表示します。

## 授業での活用

地点を変えてクリックし、送信する座標と返ってくるデータがどう変わるかを確かめます。ソースコードの `fetch()` に注目すると、ブラウザが外部サービスにリクエストを送り、応答を受け取る流れを追えます。
